# hisn-policy/v1 — specification

Policy files are TOML. The machine-readable schema is
`schemas/hisn-policy.v1.json` (generated by `hisn policy schema`, from the Rust
types via `schemars`). **Unknown keys are errors** at every level. A missing
file means built-in defaults (the table values below).

## 1. Schema

```toml
version = "hisn-policy/v1"          # required, exact string

[session]
cwd      = "."          # path; relative → resolved against the policy file's directory
                        #   (or the process cwd for --cwd / built-in defaults)
home     = "tmpfs"      # "tmpfs" | absolute host path (persistent, rw)
network  = "none"       # "none" | "host"
hostname = "hisn"       # RFC 1123 label, ≤ 63 chars

[mounts]
ro   = []               # extra read-only binds (absolute paths, recursive)
rw   = []               # extra read-write binds (absolute paths, non-recursive)
mask = []               # extra paths masked inside allowed trees
grantable_rw = []       # NEW (DESIGN D3): prefixes under which dynamic rw grants are allowed

[env]
pass = []               # names copied from the host env if set
set  = {}               # literal values

[seccomp]
extra_deny = []         # syscall names added to the built-in denylist

[limits]                # setrlimit only in v0
nofile = 65536
nproc  = 4096
```

| key | type | default | notes |
|-----|------|---------|-------|
| `version` | string | — (required) | must equal `hisn-policy/v1` |
| `session.cwd` | path | `.` | canonicalised; must exist, be a directory, and satisfy §4 rules; mounted **rw at the identical path** |
| `session.home` | `"tmpfs"` \| abs path | `"tmpfs"` | a path must exist, be owned by the caller, and not overlap runtime dir |
| `session.network` | enum | `"none"` | `"host"` additionally requires Landlock scope support (DESIGN §7) or CLI `--allow-host-abstract-sockets` |
| `session.hostname` | string | `"hisn"` | |
| `mounts.ro` / `.rw` | list of abs paths | `[]` | each must exist at session start; canonicalised; no symlinked final component accepted |
| `mounts.mask` | list of abs paths | `[]` | paths that must lie inside another allowed tree; non-existent → skipped, logged |
| `mounts.grantable_rw` | list of abs paths | `[]` | Landlock write prefixes for dynamic rw grants; also bounds `hisn grant --rw` |
| `env.pass` | list of names | `[]` | `[A-Za-z_][A-Za-z0-9_]*`; cannot name `HOME` |
| `env.set` | table name→string | `{}` | wins over `pass`; cannot set `HOME` |
| `seccomp.extra_deny` | list of syscall names | `[]` | must be known for the build arch, else error |
| `limits.nofile` / `.nproc` | u64 | 65536 / 4096 | `RLIMIT_NOFILE` / `RLIMIT_NPROC`; ≥ 1 |

Validation failures print `path.to.key: reason` and exit 125.

## 2. Resolution

`hisn run` merges, in increasing precedence: built-in defaults → policy file →
CLI flags (`--cwd`, `--network`, `--grant`). The merged, fully-resolved
(absolute, canonical) policy is written to `<session>/policy.resolved.toml`
and is what `hisn inspect` prints; the mount plan (DESIGN §4.1) is a pure
function of it plus a snapshot of which default toolchain paths exist.

## 3. Defaults that are not configurable in v0

Toolchain ro binds (`/usr /bin /sbin /lib /lib32 /lib64 /etc /opt /nix`, only
existing), default `/etc` masks (DESIGN §4.2), tmpfs sizes, `/dev` node list,
the seccomp base denylist, capability set (empty), `no_new_privs`, and the
env allowlist base (`PATH HOME TERM LANG LC_* TZ`). The brief's DO NOT ALTER
invariants forbid weakening them from policy; `seccomp.extra_deny` can only
add.

## 4. Path rules (enforced at resolve time and on every grant)

Applied to the canonical (symlink-free) form of every path in `cwd`,
`home`, `mounts.*`, `--grant`, and dynamic grants:

* **R1** may not equal, contain, or lie inside the hisn runtime root
  (`$XDG_RUNTIME_DIR/hisn`, `/tmp/hisn-$UID`);
* **R2** may not be `/`, `/proc`, `/sys`, `/dev`, or an rw/recursive ancestor
  of the runtime root;
* **R3** may not overlap a mask or a non-grant static mount except as a nested
  child of an rw/ro static mount;
* **R4** grant sources are resolved with no symlink and no magic-link
  traversal.

Violations are errors (`E_PATH_FORBIDDEN`), never silently adjusted.

## 5. Semantics

* **cwd** is rw and recursive; mounts inside it on the host (other
  filesystems) are *included* (recursive bind), so a worktree with nested
  mounts still works. Set `mounts.mask = ["<cwd>/.secrets"]` etc. to hide
  parts.
* **mask**: file → reads as empty (`/dev/null` bind); directory → empty,
  read-only tmpfs. Masking is by bind-over, so it works for any depth but is
  **not** retroactive for files created later in a *live* bind of the host
  (DESIGN §4.2).
* **home**: `"tmpfs"` → memory-backed, gone at exit. A path → persistent rw
  bind at the sandbox `$HOME` (`/run/hisn/home`); the caller accepts that the
  sandbox can write there.
* **network = "none"**: new net ns, `lo` up, nothing else. `127.0.0.1` works
  inside; any non-loopback destination fails with `ENETUNREACH`.
  **"host"**: no net ns; no filtering of any kind.
* **env**: DESIGN §8. `pass` of an unset name is a no-op.
* **limits**: applied in init before `execve`; inherited by all descendants.

## 6. CLI mapping

| CLI | policy equivalent |
|-----|-------------------|
| `--cwd DIR` | `session.cwd` |
| `--network none\|host` | `session.network` |
| `--grant PATH[:ro\|rw]` | initial grant, **same code path as a dynamic grant** (performed through the control logic right after `ready`), and thus subject to `grantable_rw` for `rw` |
| `--session-id ID` | none (`[A-Za-z0-9._-]{1,64}`; collision with a live session is an error) |

## 7. Control protocol (v0 contract)

Unix socket `<session>/control.sock` (0600). One JSON object per line, one
response line per request, in order. Max line 64 KiB.

| request | fields | success response |
|---------|--------|------------------|
| `grant` | `path` (abs), `mode` (`"ro"`\|`"rw"`, default `"ro"`), `recursive` (bool, default false) | `{"ok":true,"mount_id":N,"path":P,"mode":M}` |
| `revoke` | `path`, `kill_holders` (bool, default false) | `{"ok":true,"holders":[]}` or `{"ok":false,"error":"E_HELD","holders":[{"pid":N,"kind":"cwd\|fd\|map"}]}` (mount **is** detached either way; `ok:false` means open handles remain) |
| `list` | — | `{"ok":true,"grants":[{"path","mode","recursive","mount_id","ts"}]}` |
| `inspect` | — | `{"ok":true,"mountinfo":"<text of /proc/<init>/mountinfo>","policy":"<resolved toml>"}` |
| `kill` | `signal` (name or number; default `TERM`) | `{"ok":true}` |

Error response: `{"ok":false,"error":"<CODE>","message":"..."}` with codes
`E_BAD_REQUEST E_PATH_FORBIDDEN E_NOT_FOUND E_NOT_GRANTABLE E_EXISTS E_NOT_GRANTED
E_HELD E_INTERNAL`. A grant of an already-granted path is `E_EXISTS`
(modes are never silently changed). `hisn grant|revoke|ls|inspect|kill` are thin
clients of this socket; they resolve `--session ID` to the socket path and
refuse sessions not owned by the caller's uid.

### Audit log

`grants.jsonl` is append-only (`O_APPEND`), one object per line:
`{"ts":"RFC3339","op":"grant|revoke|…","path":"…","mode":"ro|rw","stage":"request|result","result":"ok|E_…","pid_peer":N}`.
A request line is written **before** execution so a crash leaves evidence.
It is never mounted into the sandbox.

## 8. OCI runtime-spec mapping (invariant 5)

v0 does not emit OCI bundles; this table is the contract that keeps every
construct expressible in `config.json` for the v2 conformance work.

| hisn construct | OCI `config.json` |
|----------------|-------------------|
| root = empty tmpfs, pivot_root, old root detached | `root.path` = empty dir; `root.readonly=false`; runtime does pivot_root (runc default) |
| toolchain ro binds | `mounts[]` `{destination, source, type:"bind", options:["rbind","ro","nosuid","nodev"]}` |
| cwd (rw, identical path) | `mounts[]` bind, options `["rbind","rw"]` |
| mask file | `mounts[]` bind of `/dev/null`, `["ro"]` (or `linux.maskedPaths[]`) |
| mask dir | `mounts[]` `{type:"tmpfs", options:["ro","size=0"]}` (or `linux.maskedPaths[]`) |
| `/tmp /run $HOME` | `mounts[]` `{type:"tmpfs", options:["nosuid","nodev","mode=…","size=…"]}` |
| `/proc` | `mounts[]` `{type:"proc", source:"proc"}` + `linux.readonlyPaths[]` (`/proc/sys`, …) |
| `/dev` devices + devpts | `mounts[]` `tmpfs` + `devpts` (`newinstance,ptmxmode=0666`) + `linux.devices[]` (null, zero, full, random, urandom, tty) |
| no `/sys` | omit the `sysfs` mount |
| `session.network = "none"` | `linux.namespaces` includes `{type:"network"}` (no path), loopback set up by runtime |
| `session.network = "host"` | `linux.namespaces` omits `network` |
| user/mnt/pid/ipc/uts ns | `linux.namespaces[]` types `user mount pid ipc uts` |
| uid/gid single map | `linux.uidMappings[]`, `linux.gidMappings[]` = `{containerID:u, hostID:u, size:1}` |
| `session.hostname` | `hostname` |
| caps all dropped | `process.capabilities.{bounding,effective,inheritable,permitted,ambient}` = `[]` |
| `no_new_privs` | `process.noNewPrivileges=true` |
| seccomp denylist | `linux.seccomp` `{defaultAction:"SCMP_ACT_ALLOW", architectures:[…], syscalls:[{names:[…], action:"SCMP_ACT_ERRNO"\|"SCMP_ACT_KILL_PROCESS"}]}` — clone/clone3 rules need `args[]` (`SCMP_CMP_MASKED_EQ`) |
| Landlock | **no OCI equivalent** (hisn extension; carry as annotation `org.hisn.landlock=…`) |
| env scrub + `env.set` | `process.env[]` (fully explicit list; runtime must not inherit) |
| `limits.nofile/nproc` | `process.rlimits[]` `RLIMIT_NOFILE`, `RLIMIT_NPROC` |
| `no_new_privs` + securebits | `process.noNewPrivileges` (securebits: no OCI field → annotation) |
| dynamic grants | **no OCI equivalent** (runtime-spec is static); v2 exposes them as a hisn control extension |
| session dir / control socket | outside the spec; never in `mounts[]` |

Landlock, securebits, dynamic grants and revoke-with-holders have no
runtime-spec representation; they are listed here so v2 conformance means
"accept/emit standard `config.json`, with hisn extensions as annotations", not
"drop them".
