### Code structure (relevant)

- **verdict_table** (`src/notif.rs:2720`): 8 entries. The `Listen` entry
  is already `SupervisorExecuted` in the enum — only its rationale text
  describes the INET/AF_UNIX split. `KernelContinued` for `ConnectUnix`
  and `BindUnix`.
- **verdict_table_continue_only_where_covered** test
  (`src/notif.rs:4110`): asserts `KernelContinued` only for
  `ConnectUnix | BindUnix`. The `Listen` entry is in the "never
  `KernelContinued`" list. The test passes today despite the AF_UNIX
  listen gap — the table is documentation, not coupled to the dispatch
  code.
- **Listen handling** (`src/notif.rs:1429-1456`):
  - INET listen (`d_is_inet` true): `Sandbox` → supervisor executes
    `listen()` on dup; `Host | Unknown` → refuse.
  - Non-INET listen (`d_is_inet` false): `Sandbox` → `FLAG_CONTINUE`;
    `Host | Unknown` → refuse.
  - `d_is_inet` (line 1559) is called **only** at line 1434. Collapsing
    the two branches will make it dead — clippy `-D warnings` will fail
    if it is not removed.
- **`in_hostsocket` test** (`net_helper.py:663`): expects `listen` on a
  kept host socket to **succeed** ("want success", line 696). But the
  code refuses it (`SockNs::Host => refuse_implicit(EACCES)`, line 1441).
  This test is wrong — the code correctly refuses because a
  supervisor-namespace socket's listen would auto-bind a port in the
  supervisor namespace. `net_cases.sh:475` expects `listen=ok`. Both must
  be corrected to expect `EACCES`.
- **`handle_implicit_call` doc comment** (`src/notif.rs:1421-1428`):
  says "AF_UNIX listen records the caller's credentials (SO_PEERCRED),
  so for non-INET sandbox sockets the call is continued." This becomes
  stale after Block 3.
- **Landlock** (`src/landlock.rs`): `TARGET_ABI=V6`, `MIN_NET_ABI=V4`,
  `deny_tcp` for open mode (`BindTcp | ConnectTcp`, no allow rules).
  Landlock covers only TCP bind/connect — **not** listen auto-bind and
  **not** AF_UNIX. The forced-continue check must account for this.
- **decide()** (`src/notif.rs:441`): AF_UNIX → `Continue`, loopback →
  `Continue`.
- **net_cases.sh**: ~110+ hermetic test cases. Already has parity test
  `in-parity` with AF_UNIX path and abstract (line 769).
- **host-verify-network.sh**: build → release-gate plain → release-gate

- **release-gate.sh**: step 0 private-details, step 0b force-continue
