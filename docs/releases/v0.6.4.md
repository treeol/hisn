# Release notes — hisn 0.6.4

0.6.4 lets a command outlive the call that started it, and makes the journal
cursor cheap. The control protocol moves to revision 4. The version existing
commands declare stays 3, so every command that uses no new option sends the
same bytes as 0.6.3, and a 0.6.3 CLI works against a 0.6.4 supervisor.

## For callers

- **Detached exec.** `hisn exec --detach` returns at once with
  `{"schema":"hisn-exec-start/v1","exec_id","incarnation","pid"}`. The command
  runs in the session's sandbox with the same network policy and seat
  attribution as any exec and survives the client. At most 32 per session.
- **Status, output, signal.** `hisn exec-status`, `hisn exec-output --offset N
  [--stream stderr]` (reports `next`, `rotated_away`, `eof`), `hisn exec-signal
  --signal TERM|INT|KILL|HUP`. The last 16 MiB of each stream are kept.
  Owner: all. Member: reads any exec, signals its own seat's. Observer: status.
- **Journal.** `--after-wseq` seeks instead of reading the whole file (median
  114 ms to 3 ms on 100 000 records, test machine). A corrupt line becomes a
  `journal/unreadable` record and the cursor moves on; a real hole is still
  exit 4. `journal --info` has an `unreadable` count.
- **Guide.** [docs/EXTERNAL-CALLERS.md](../EXTERNAL-CALLERS.md),
  [docs/CONTROL-PROTOCOL.md](../CONTROL-PROTOCOL.md),
  [ADR 0023](../adr/0023-detached-exec.md).

## Changed

- The legacy `signal` op refuses a detached exec; use `exec-signal`.
- `journal --info` scans each journal file once; later calls are cheap.
- Stopping a session ends its detached execs and lists them in `session/stop`.
- A running detached exec keeps the session from being idle.

## Known limits

- If a stream file cannot be rotated, it grows past 8 MiB; nothing is lost.
- Output cannot be read after the session has stopped (files stay on disk).
- On the cursor path the stderr count of skipped lines covers only what was read.
- A killed reader can leave an index temp file until the next index write.
- `setsid` still works with its old limits.
